# Cisco Packet Tracer Network Laboratory Projects

A collection of network laboratory projects developed using Cisco Packet Tracer as part of my Computer Engineering coursework.

## Projects

### 1. Network Configuration
Design and configuration of interconnected computer networks using Cisco Packet Tracer.

### 2. Web Server and Network Communication
Configuration of a network environment including a web server and client devices.

### 3. IoT Network
Design and configuration of an IoT-based network using Cisco Packet Tracer.

### 4. Smart Home
Simulation of a smart home environment using IoT devices and network components.

## Tools

- Cisco Packet Tracer
- Networking Fundamentals
- TCP/IP
- LAN/WAN Configuration
- IoT Networking
